# Text

Пакет ComfyUI для запросов к локальным языковым моделям. [DSN Comfy Packs](../README.md)

## Функции

| Нода | Назначение |
| --- | --- |
| Request Setup | Сервер, модель и параметры запроса |
| Prompt | Промпт из поля или файла UTF‑8 |
| Text Context | Пути к файлам TXT, MD, JSON и CSV и объединение их с текстом из графа |
| Result Setup | Имя папки и результата, дата и время, сохранение TXT и MD |
| Generate Text | Текст ответа, причина завершения и предпросмотр |

## Требования

ComfyUI с API нод V3. Сервер предоставляет OpenAI-совместимые `GET /v1/models` и `POST /v1/chat/completions`. Общий контракт подходит для llama.cpp, Ollama и LM Studio. Рабочая проверка выполнена на llama.cpp.

## Установка

Установить каталог `Text` в `custom_nodes` по [общей инструкции](../README.md#установка). Скопировать [пример конфига](config.example.json) в `~/.dsn-comfy/text/config.json` или указать его путь в переменной `DSN_TEXT_CONFIG` процесса ComfyUI. Заполнить адреса и API-имена моделей. Параметр `api_key_env` профиля задает имя переменной ключа, если сервер требует авторизацию.

В `models` задаются ID и отображаемые имена. Профиль в `servers` сопоставляет эти ID с именами, которые возвращает его `/v1/models`. Путь `prompts` считается от `root`, а относительный `root` — от каталога конфигурации. Для CJA PC это `Data/Prompts` внутри рабочего корня AI.

Любая модель, назначенная профилю, появляется в категории **Text** библиотеки моделей при запуске Comfy. Один ID дает одну карточку со списком профилей. Библиотека строится из конфигурации; доступность выбранной модели проверяется через `/v1/models` при запросе. Температура по умолчанию — 0,8, лимит ответа — 8000 токенов. Профиль может задавать другие значения.

Для автозапуска задать в профиле `launch` как массив аргументов от исполняемого файла до параметров. Сервер должен работать в этом процессе, с адресом `127.0.0.1` или `::1`. Скрипт, который запускает сервер в фоне и сразу завершается, для этого режима не подходит. При открытии графа используется только конфиг. Запущенный вручную экземпляр доступен для запросов и сохраняется при включенном автостопе. Для сервера пакета переключатель **Остановить после запроса** завершает его после обработки запроса. Таймауты `startup_timeout` и `timeout` указываются в секундах.

## Использование

Открыть [Генерацию текста](<workflows/Генерация текста.app.json>) как приложение или граф. Выбрать сервер и модель, затем ввести промпт или указать путь к TXT/MD. Для запроса по одному промпту достаточно Request Setup, Prompt и Generate Text.

Поля путей принимают полный путь или путь от рабочего корня `root`, например `Input/заметки.md` или `Data/Prompts/итоги.md`. Промпт, указанный только именем файла, также ищется в `prompts`, если его нет в рабочем корне.

В **Text Context** задается количество полей для путей (до восьми). Пустые поля пропускаются. Сначала передается подключенный исходный текст, затем содержимое файлов в порядке полей. В «Приложении» подсказка открывается по наведению или нажатию на иконку информации рядом с полем.

В **Result Setup** оба формата включены по умолчанию. Пустой каталог использует Output Comfy. При совпадении имени файлы добавляются в существующую папку и нумеруются. Блок «Результат» показывает файлы и на локальном Windows позволяет открыть папку. В графе ответ идет под этим блоком. В «Приложении» ответ виден в основной области, а при успешном запуске без экспорта карточка скрыта.

## Проверка

В корне репозитория запустить `python -B -m unittest discover -s Text/Tests -v` из окружения ComfyUI.
