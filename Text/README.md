# Text

Пакет ComfyUI для запросов к локальным языковым моделям. [DSN Comfy Packs](../README.md)

## Функции

| Нода | Назначение |
| --- | --- |
| Request Setup | Сервер, модель и параметры запроса |
| Prompt | Промпт из поля или файла UTF‑8 |
| Text Context | Пути к файлам TXT, MD, JSON и CSV и объединение их с текстом из графа |
| Result Setup | Имя папки и результата, дата и время, сохранение TXT и MD |
| Generate Text | Текст ответа, причина завершения и предпросмотр |

## Требования

ComfyUI с API нод V3. Сервер предоставляет OpenAI-совместимые `GET /v1/models` и `POST /v1/chat/completions`. Общий контракт подходит для llama.cpp, Ollama и LM Studio. Рабочая проверка выполнена на llama.cpp.

## Установка

Установить каталог `Text` в `custom_nodes` по [общей инструкции](../README.md#установка). Скопировать [шаблон](config.example.json) в `package-configs/text-config.json` внутри пользовательского каталога экземпляра ComfyUI. Для другого расположения задать полный путь к файлу через `COMFY_TEXT_CONFIG` в окружении процесса ComfyUI. В шаблоне заменить адрес сервера и `model-id-from-api` на фактический ID из `GET /v1/models`. Параметр `api_key_env` задает имя переменной с ключом, если сервер требует авторизацию.

При `root: null` рабочим корнем служит базовая папка экземпляра ComfyUI. Явный относительный `root` отсчитывается от папки конфига, а пути в `paths` и пути к манифестам — от рабочего корня. При `paths.model_catalog: null` карточки хранятся в `text-model-catalog` рядом с конфигом. Input, Output и временный каталог предпросмотра задает ComfyUI.

В `models` ключом служит ID пакета. Поле `name` задает название в интерфейсе, а необязательное `manifest` — путь к локальному JSON с полями `source`, `revision` и `format`. В карточке видны серверы из профилей и доступные сведения из манифеста. Каждый профиль в `servers` сопоставляет ID пакета с именами моделей своего API.

При включенной системе ассетов ComfyUI (`--enable-assets`) каждая модель, назначенная профилю, появляется в категории **Text** библиотеки моделей. Один ID дает одну карточку со списком профилей. Если модель временно убрана из конфигурации, ее пользовательские теги и заметки хранятся рядом с каталогом карточек и восстанавливаются при возврате того же ID. Доступность выбранной модели проверяется через `/v1/models` при запросе. Температура по умолчанию — 0,8, лимит ответа — 8000 токенов. Профиль может задавать другие значения.

Шаблон подключается к уже работающему серверу. Для автозапуска заполнить `launch.executable`, `launch.args` и при необходимости `launch.cwd`. Если `cwd` пуст, команда запускается из `root`. Для llama.cpp путь к весам можно передать через `--model`, а путь к пресету через `--models-preset`. Сервер должен работать в запущенном процессе и слушать `127.0.0.1` или `::1`. Переключатель **Остановить после запроса** действует только на процесс пакета. Таймауты в `defaults.connection` указаны в секундах. Раздел `defaults` задает начальные значения новых нод, сохраненные поля графа имеют приоритет.

## Использование

Открыть [Генерацию текста](<workflows/Генерация текста.app.json>) как приложение или граф. Выбрать сервер и модель, затем ввести промпт или указать путь к TXT/MD. Для запроса по одному промпту достаточно Request Setup, Prompt и Generate Text.

Поля путей принимают полный путь или путь от рабочего корня `root`, например `Input/заметки.md` или `Data/Prompts/итоги.md`. Промпт, указанный только именем файла, также ищется в `prompts`, если его нет в рабочем корне.

В **Text Context** задается количество полей для путей (до восьми). Пустые поля пропускаются. Сначала передается подключенный исходный текст, затем содержимое файлов в порядке полей. В «Приложении» подсказка открывается по наведению или нажатию на иконку информации рядом с полем.

В **Result Setup** оба формата включены по умолчанию. Пустой каталог использует Output Comfy. При совпадении имени файлы добавляются в существующую папку и нумеруются. Блок «Результат» показывает файлы и на локальном Windows позволяет открыть папку. В графе ответ идет под этим блоком. В «Приложении» ответ виден в основной области, а при успешном запуске без экспорта карточка скрыта.

## Проверка

В корне репозитория запустить `python -B -m unittest discover -s Text/Tests -v` из окружения ComfyUI.
