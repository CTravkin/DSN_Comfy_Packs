# Text

Пакет ComfyUI для запросов к языковым моделям по тексту и материалам из файлов. [DSN Comfy Packs](../README.md)

## Функции

| Нода | Назначение |
| --- | --- |
| Request Setup | Сервер, модель и параметры запроса |
| Prompt | Промпт из поля или файла UTF‑8 |
| Text Context | Пути к файлам TXT, MD, JSON и CSV и объединение их с текстом из графа |
| Result Setup | Имя папки и результата, дата и время, сохранение TXT и MD |
| Generate Text | Текст ответа, причина завершения и предпросмотр |

## Стек

Python и aiohttp в окружении ComfyUI. Генерацию выполняет отдельный сервер модели.

## Требования

Сервер модели должен поддерживать OpenAI-совместимые `GET /v1/models` и `POST /v1/chat/completions`. Рабочие прогоны выполнены на llama.cpp.

В контекст, выделенный сервером для запроса, должны помещаться промпт, материалы, служебные токены шаблона и заданный лимит ответа. При переполнении сервер может отклонить запрос или обрезать часть входа и вернуть ответ без ошибки.

### Конфигурация

Шаблон находится в [config.example.json](config.example.json). ComfyUI ищет рабочую копию в `package-configs/text-config.json` внутри своего пользовательского каталога. Для другого размещения задать полный путь через `COMFY_TEXT_CONFIG` в окружении процесса ComfyUI. В существующих установках `DSN_TEXT_CONFIG` читается как резервный вариант.

| Раздел | Назначение |
| --- | --- |
| `root` | Рабочая папка для относительных путей. При `null` используется базовая папка ComfyUI. Относительное значение `root` отсчитывается от папки конфига |
| `paths` | Каталог промптов и каталог карточек моделей. При `model_catalog: null` карточки хранятся в `text-model-catalog` рядом с конфигом |
| `models` | ID модели внутри Text, отображаемое имя `name` и необязательный путь `manifest` к JSON со сведениями о модели |
| `servers` | Профили подключения, адрес API, сопоставление ID Text с ID модели на сервере, модель по умолчанию и необязательная команда запуска |
| `defaults` | Начальные значения соединения, генерации, источника промпта, числа полей материалов и экспорта. Таймауты указаны в секундах. Сохраненные поля графа имеют приоритет |

Пути в `paths` и `manifest` отсчитываются от рабочего корня. Input, Output и временный каталог предпросмотра задает ComfyUI.

## Эксплуатация

### Установка

Разместить пакет по [общей инструкции](../README.md#установка). Подготовить сервер и модель по документации выбранного сервера.

### Настройка

1. Скопировать шаблон в рабочий файл конфигурации.
2. В `servers.local.url` указать базовый адрес API с `/v1`. В `servers.local.models` заменить `model-id-from-api` на точный `id` из ответа `GET /v1/models`. Для авторизации указать в `api_key_env` имя переменной окружения, в которой хранится ключ.
3. Для уже работающего сервера оставить `launch: null`. Для автозапуска заполнить `launch.executable` и список `launch.args`. При пустом `launch.cwd` запуск идет из `root`. Адрес автозапуска должен использовать `127.0.0.1` или `::1`. Для llama.cpp веса можно задать через `--model`, а пресет моделей через `--models-preset`.
4. Перезапустить ComfyUI и проверить, что в **Request Setup** доступны профиль и модель.

При включенной системе ассетов одна модель Text отображается одной карточкой со списком профилей. Карточка дополняется доступными сведениями из `manifest`, например `source`, `revision` и `format`. Пользовательские теги и заметки восстанавливаются при возврате модели с тем же ID.

#### Размер контекста

Настроить контекст на сервере с учетом размера запроса, возможностей модели и доступной памяти. В llama.cpp размер задается аргументом `--ctx-size`. При автозапуске из Text его можно указать в `servers.local.launch.args`.

### Использование

Открыть [Генерацию текста](<workflows/Генерация текста.app.json>) как приложение или граф. Выбрать сервер и модель, затем ввести промпт или указать путь к TXT/MD. Для запроса по одному промпту достаточно Request Setup, Prompt и Generate Text.

Поля путей принимают полный путь или путь от рабочего корня `root`, например `Input/заметки.md` или `Data/Prompts/итоги.md`. Промпт, указанный только именем файла, также ищется в `prompts`, если его нет в рабочем корне.

В **Text Context** задается количество полей для путей (до восьми). Пустые поля пропускаются. Сначала передается подключенный исходный текст, затем содержимое файлов в порядке полей. В «Приложении» подсказка открывается по наведению или нажатию на иконку информации рядом с полем.

В **Request Setup** можно изменить температуру и лимит ответа. В шаблоне заданы 0,8 и 8000 токенов. Переключатель **Остановить после запроса** действует только на сервер, запущенный Text.

В **Result Setup** оба формата включены по умолчанию. Пустой каталог использует Output Comfy. При совпадении имени файлы добавляются в существующую папку и нумеруются. Блок «Результат» показывает файлы и при локальном подключении на Windows позволяет открыть папку. В графе ответ идет под этим блоком. В «Приложении» ответ виден в основной области, а карточка «Результат» появляется при наличии файлов, сообщений о завершении или счетчиков токенов.

Счетчики показывают число токенов промпта с материалами и число токенов ответа по данным сервера. По этим числам нельзя подтвердить, что весь вход был обработан.

### Проверка

Из корня репозитория запустить команду с Python экземпляра ComfyUI. В `PYTHONPATH` должен быть доступен каталог ядра ComfyUI.

```sh
python -B -m unittest discover -s Text/Tests -v
```
