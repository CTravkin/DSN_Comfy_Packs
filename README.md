# DSN Comfy Packs

DSN Comfy Packs расширяет ComfyUI для локальной обработки речи и работы с языковыми моделями. Пакеты можно устанавливать отдельно и сочетать в одном графе.

## Компоненты

| Компонент | Тип | Назначение |
| --- | --- | --- |
| [Speech](Speech/README.md) · `Speech/` | Library | Локальная обработка речи и голосов с готовыми приложениями ComfyUI |
| [Text](Text/README.md) · `Text/` | Library | Текстовые запросы к локальным моделям, сбор материалов и сохранение ответа |

## Эксплуатация

### Установка

1. Подготовить [ComfyUI](https://docs.comfy.org/) с API нод V3.
2. Скопировать каталог выбранного пакета целиком в `custom_nodes` экземпляра. Файл `__init__.py` должен находиться непосредственно в каталоге пакета, например `custom_nodes/Speech/__init__.py`.
3. Выполнить разделы «Установка» и «Настройка» выбранного пакета из таблицы выше.
4. Перезапустить ComfyUI и найти пакет в библиотеке нод.

Для карточек моделей нужна включенная система ассетов ComfyUI. Если она выключена, добавить `--enable-assets` к аргументам запуска ComfyUI. Ноды работают и без карточек.

### Использование

Файлы `.app.json` из каталога `workflows/` можно перетащить на полотно ComfyUI. Переключатель **Граф / Приложение** меняет режим просмотра открытого процесса. Чтобы добавить процесс в свою библиотеку, сохранить его в ComfyUI.
