# DSN Comfy Packs

Наборы пользовательских нод и готовых рабочих процессов для ComfyUI. Каждый пакет устанавливается отдельно и содержит документацию по своим зависимостям, моделям и рабочим процессам.

## Компоненты

| Компонент | Тип | Назначение |
| --- | --- | --- |
| [Speech](Speech/README.md) · `Speech/` | Library | Локальная обработка речи и голосов с готовыми приложениями ComfyUI |
| [Text](Text/README.md) · `Text/` | Library | Текстовые запросы к локальным моделям, сбор материалов и сохранение ответа |

## Эксплуатация

### Установка

1. Подготовить [ComfyUI](https://docs.comfy.org/) и выполнить требования выбранного пакета.
2. Скопировать каталог пакета целиком в `custom_nodes` используемого экземпляра ComfyUI. Например, для Speech файл `__init__.py` должен находиться в `custom_nodes/Speech/`.
3. Перезапустить ComfyUI. Ноды пакета появятся в библиотеке нод.

### Использование

Файлы из каталога `workflows/` выбранного пакета открываются перетаскиванием JSON на полотно ComfyUI. Для добавления в библиотеку рабочих процессов граф сохраняется через **Файл → Сохранить как**.
